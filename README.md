# Geelong Night Routes

A minimal night-sky route planner for Geelong and nearby dark-sky destinations.

## Features

- Dijkstra shortest-path algorithm
- Numbered route sequence and directional arrows
- Distance labels in kilometres
- Responsive SVG route diagram (no map API key required)
- Browser location permission
- One-day itinerary with night-sky viewing suggestions
- Static HTML/CSS/JavaScript — easy to deploy on GitHub Pages or Vercel

## Run locally

Open `index.html` in a browser. For geolocation, serve the folder over HTTPS or localhost (for example with a local static server), because browsers restrict geolocation on insecure origins.

## Notes

Distances are approximate route-planning weights for the demo and should not replace live road navigation. Check current road, park, weather and fire conditions before travel.
